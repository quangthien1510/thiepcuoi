# Nhạc nền

1. Tạo/đặt file nhạc MP3 vào `public/music/`.
2. Mặc định component tìm file `public/music/wedding.mp3`.
3. Nếu tên khác, sửa `weddingData.music.src` trong `src/data/wedding.ts`.
4. Nhạc bắt đầu sau lần chạm/click đầu tiên của khách để tương thích chính sách autoplay của iPhone/Android.
5. Nút `♫` nằm nổi bên trái phía dưới; bấm để bật/tắt.
